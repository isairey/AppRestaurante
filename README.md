# 🍽️ Sistema de Restaurante — Aplicación de Escritorio en Java

Aplicación de escritorio desarrollada en **Java** para la gestión integral de un restaurante, permitiendo administrar pedidos, mesas, productos y ventas de manera eficiente.

---

## 🚀 Descripción

El **Sistema de Restaurante** es una solución diseñada para optimizar las operaciones dentro de un establecimiento gastronómico. Permite llevar el control de pedidos en tiempo real, gestionar mesas y generar reportes de ventas.

Está orientado a negocios que buscan una herramienta sencilla pero funcional para mejorar su flujo de trabajo.

---

## 🎯 Características principales

* 🍴 **Gestión de mesas**

  * Asignación y liberación de mesas
  * Estado de ocupación en tiempo real

* 🧾 **Pedidos**

  * Creación de pedidos por mesa
  * Agregar y eliminar productos
  * Actualización de estado (en preparación, servido, pagado)

* 📦 **Gestión de productos**

  * Registro de platillos y bebidas
  * Control de precios

* 💰 **Ventas**

  * Cálculo automático del total
  * Registro de ventas realizadas

* 📊 **Reportes**

  * Historial de pedidos
  * Reporte de ingresos

* 🔐 **Sistema de usuarios**

  * Roles básicos (Administrador / Cajero)

---

## 🛠️ Tecnologías utilizadas

* ☕ Java (JDK 8+)
* 🖥️ Swing / JavaFX (interfaz gráfica)
* 🗄️ Base de datos: MySQL / SQLite
* 🔗 JDBC para conexión a base de datos
